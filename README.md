## Bankroll tracker

Content types for the bankroll tracker are created with a Contentful migration. Run it once, before deploying code that queries the new fields:

```bash
npx contentful-cli login
npx contentful-cli space migration --space-id hf234a786srd --environment-id master contentful/migrations/01-bankroll-tracker.js
```

Then in Contentful create a Split Rule entry (50 / 30 / 20, weekly profit) and a Bankroll entry linked to the `2026-regular-season` Season. The record page lives at `/nfl/<season slug>/record`. Outside production, `/nfl/sample/record` shows the page with made-up picks.
